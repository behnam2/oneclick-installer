# vpn-ui-setup

Vendored copy of the [Sir-MmD/vpn-ui](https://github.com/Sir-MmD/vpn-ui)
official deploy script, used by **oneclick-installer**.

- `deploy.sh` — downloads and installs the vpn-ui panel binary and systemd
  service to `/opt/vpn-ui`, and the `vpn-ui` management menu.

Licensed under **GPLv3** (see `LICENSE`). All copyright notices preserved.

Uninstall: `sudo /opt/vpn-ui/vpn-ui-amd64 --uninstall`
